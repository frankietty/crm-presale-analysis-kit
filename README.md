# CRM 售前需求分析与销售漏斗演示工具箱

> 面向 CRM 产品售前 / 产品分析场景的轻量演示工具箱。30 秒向客户或面试官演示「CRM 如何把销售流程标准化、并沉淀数据支持经营分析」。单文件、零依赖、离线可运行——双击即演示。

## Demo 功能

**`demo/crm-pipeline-demo.html`** —— CRM 销售管道看板：

- **两套内置行业场景**：B2B 软件销售 / 教育机构招生（同样的流程结构适配不同行业，验证 CRM「流程可配置」的产品思路）
- **5 阶段销售管道**：线索 → 初步沟通 → 方案/报价 → 谈判 → 成单（+ 流失池），每个阶段标注「要解决的业务问题」
- **销售流程路径说明**：一键展示每阶段「客户在做什么 / 销售要做什么 / 流转标准」——对应售前向客户讲 CRM 价值的核心讲法
- **转化率漏斗分析**：各阶段商机数与向上转化率，自动定位流程瓶颈阶段——演示 CRM「数据沉淀 → 经营分析」的价值闭环
- **交互演示**：点击推进商机、标记流失，管道金额 / 赢单率实时重算

## 快速开始

1. 下载 `demo/crm-pipeline-demo.html`
2. 双击用浏览器打开（无需服务器、无需联网）
3. 依次点击「销售流程路径说明」→「转化率 / 漏斗分析」，配合看板演示

## 面向的客户场景

- 客户问「CRM 到底解决什么问题」→ 用「流程路径说明」页讲清楚
- 客户问「上了 CRM 管理层能看到什么」→ 用「漏斗分析」页演示数据价值
- 客户是不同行业 → 切换第二套场景，演示流程可配置性
