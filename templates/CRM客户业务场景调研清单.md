# CRM 客户业务场景调研清单（售前 / 产品分析版）

> 用途：客户表达「想上 CRM / 优化 CRM」时，按本清单澄清业务场景，把模糊需求转成可分析的流程与数据需求，避免"上来就讲功能"。

## 一、组织与角色（谁在用？）

| 调研项 | 要点 |
|------|------|
| 销售组织结构 | 直销 / 渠道 / 电销？几层管理？决定审批流与数据权限设计 |
| 角色清单 | 一线销售 / 销售主管 / 市场运营 / 管理层，各角色看什么、做什么 |
| 谁录入数据 | 一线不愿录入是 CRM 失败第一原因——先问清录入动机与负担 |

## 二、现有销售流程（现在怎么做的？）

- 从「拿到线索」到「签约回款」目前分几步？每步谁负责、平均多久？
- 商机怎么判定真假？有没有统一标准？（多数客户没有——这正是 CRM 流程设计的切入点）
- ⚠️ 记录现状流程图，再对照标准管道找差异，不要直接按客户现状照搬

## 三、数据现状盘点（有什么数据？）

| 数据类型 | 盘点要点 |
|------|------|
| 客户数据 | 存在哪（Excel / 微信 / 老系统）？重复率？唯一标识？ |
| 商机/订单 | 有没有阶段划分？历史成交周期、金额分布？ |
| 跟进记录 | 有没有沉淀？能否还原用户行为轨迹（拜访/电话/微信）？ |

## 四、痛点与目标（怎么算做好？）

- 痛点排序：线索浪费 / 跟进遗漏 / 管理层看不到真实管道 / 报表靠手工？
- 目标量化：线索转化率、成单周期、人均产出——验收标准前置约定

## 五、结论输出（三档判定）

- ✅ **可满足**：标准 CRM 流程 + 配置即可覆盖 → 输出方案路径
- ⚠️ **部分满足**：需定制开发或流程改造 → 明确边界与成本
- ❌ **暂不建议**：数据基础太弱 / 组织未就绪 → 给出分阶段实施建议
