# CRM 产品对比分析模板（产品分析 / 售前版）

> 用途：竞品对比、产品线对比、方案选型论证。核心原则：**对比维度跟着客户需求走，不罗列功能清单**。

## 一、对比对象与定位

| 产品 | 厂商 | 目标客户 | 定位一句话 |
|------|------|------|------|
| 产品 A | | | |
| 产品 B | | | |
| 产品 C | | | |

## 二、需求维度对比（先定客户最看重的 3-5 个维度，再对比）

> 维度权重来自《CRM客户业务场景调研清单》的调研结论，避免"为对比而对比"。

| 维度 | 权重 | 产品 A | 产品 B | 产品 C | 说明 |
|------|------|------|------|------|------|
| 销售流程贴合度 | 高 | | | | 是否支持客户现有流程 / 需要改流程 |
| 行业化程度 | 高 | | | | 有无行业模板、行业案例 |
| 数据分析与报表 | 中 | | | | 管理层能否自助看管道、漏斗 |
| 实施与上手成本 | 中 | | | | 录入负担、培训周期、迁移难度 |
| 生态与集成 | 低 | | | | 与现有系统（ERP/企微/邮件）打通 |

评分方式：每维度 1-5 分 × 权重，加权汇总；**结论必须带客户场景，不写"哪个产品好"，只写"在客户场景下哪个更适配、为什么"**。

## 三、差异化结论（三段式）

1. **适配结论**：客户场景下推荐哪个 / 哪种组合，核心理由（不超过 2 条）
2. **风险提示**：推荐方案的 1-2 个主要短板与应对
3. **证据来源**：官网文档 / 演示环境 / 客户案例 / 试用手记，可追溯

## 四、常见误区

- ❌ 只比功能清单数量——功能多 ≠ 匹配客户流程
- ❌ 拿厂商宣传页当数据源——尽量用演示环境实测
- ❌ 结论没有客户场景——"A 比 B 好"这种结论不可用
